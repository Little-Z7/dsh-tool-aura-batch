# dsh-tool-aura-batch

DeepSeek Harness（DSH）插件：把剧本和参考素材整理成 **灵环 TV「导入分镜与参考素材」** 能直接导入的格式 ——
一个 zip，里面是整集的分镜文档和按名称命名、分好类的参考图。导入后自动拆成镜头、配好参考图，再一键「批量生成分镜视频」。

不联网、不需要账号，只读写你指定的本地文件。

## 工具（3 个）

| 工具 | 说明 |
| --- | --- |
| `aura_batch_format` | 返回灵环批量导入格式：zip 的结构、分镜文档每组的写法（【参考素材分工】图N：名称、时长 / 画幅、推荐小节）与一组模板 |
| `aura_batch_check` | 按灵环的导入规则检查分镜文档（.md / .txt / .csv）：切成几组（认不出模板时与平台同走兼容模式）、每组时长 / 画幅 / 参考登记、哪些小节会填进分镜表；给了参考目录还会核对每个名称配不配得上文件、归角色 / 场景 / 道具哪一类；「只有提示词的参考」会标出来，缺台词的音频、按提示词生成的参考视频直接报错 |
| `aura_batch_pack` | 打包：分镜文档放根目录，参考图按分镜里的名称重新命名、分进 `参考图/角色|场景|道具/`，输出 `<集名>-全套.zip` |

读 Word / PDF 剧本、改写成分镜文档，由 Agent 用 DSH 自带的读写文件能力完成；本插件负责「平台认什么」和「打成平台能导入的包」。

## 用法

对 Agent 说，例如：

> 把 ~/剧本/第01集.docx 按灵环批量导入格式改写成分镜文档，参考图在 ~/剧本/参考图，检查没问题后打包。

Agent 会依次：调用 `aura_batch_format` 看格式 → 读剧本、写出 `第01集-分镜提示词.md` → `aura_batch_check` 检查并修正 → `aura_batch_pack` 打包。
然后在灵环 TV 画布里打开脚本节点 →「导入分镜与参考素材」→ 上传这个 zip。

## 交付格式

```
<剧名>-第01集-全套.zip
├── <剧名>-第01集-分镜提示词.md      分镜文档，只放一份（md / txt / Excel / CSV）
└── 参考图/
    ├── 角色/<名称>.png              文件名 = 分镜里「图N：名称」的名称
    ├── 角色/<名称>/正面.jpg         也可以用文件夹名当名称
    ├── 场景/<名称>.png
    └── 道具/<名称>.png
```

只认普通 zip（rar / 7z、加密、超过 4GB 的读不了）；图片支持 png / jpg / webp / gif，同名只用第一张。
灵环 TV 的导入弹窗里有同一份「压缩包怎么整理」说明和分镜模板下载。

分镜文档要点（完整说明见 `aura_batch_format`）：

- 一组 = 一条视频（一次生成），推荐每组以「# 第N组 标题」开头，或组与组之间单独一行 `---`；**认不出也能导**：平台走兼容模式，按「镜头1 / 分镜一」、markdown 标题、行首编号或空行切镜头（与 `aura_batch_check` 报的切法一致），没有「提示词」列的表格每行各列拼成提示词；
- 参考登记写法放宽：「图1：程野」「图1 程野」「【图1】程野」、一行多条、文档开头统一登记都认；每组最多 9 张，名称与参考文件名一致；
- **没有文件就按提示词生成**：「图1：程野｜提示词：…」配不上文件也建成待生成资产；音频写「音频1：程野｜台词：…｜音色：…」（必须有台词）；参考视频不能生成，必须配文件；
- 正文用「图N」指代参考图；每组写「时长：N秒。」「画幅：16:9横屏」—— **批量生成按每组自己的时长与画幅出片**，没写时长按 5 秒、没写画幅按 16:9；
- 【画面内容】【焦段与景别】【机位与运镜】【光影】【Dialogue】【声效总控】会填进灵环分镜表对应的列；Excel / CSV 用同一套列（xlsx 请另存为 csv）。

## 配置

| 键 | 说明 |
| --- | --- |
| `defaultDuration` | 格式模板里每组的默认时长（秒），默认 15 |
| `defaultRatio` | 格式模板里的默认画幅，默认 16:9 |

## 与灵环平台保持一致

`src/format.ts` 的切组、读时长 / 画幅 / 图N、名称配图、角色 / 场景 / 道具归类、【小节】对应分镜表列，
与灵环仓库 `web/src/lib/batchVideo/{parse,match,zipRefs,tvImport}.ts` 逐条一致；`src/loose.ts` 的兼容模式切法与宽松参考登记
移植自 `web/src/lib/batchVideo/looseParse.ts`（平台提交 284fe1d1），`src/spec.ts` 的格式说明照 `web/src/lib/batchVideo/importGuide.ts` 同步。
平台规则改了，这里同步改并补用例。

## 更新记录

- **0.4.0**：跟上平台导入规则——认不出模板的分镜文档与平台同走兼容模式（镜头标记 / 标题 / 行首编号 / 空行 / 整篇，检查会报用了哪种切法）；宽松参考登记（`图1 程野`、`【图1】程野`、一行多条、文档开头统一登记）；「只有提示词的参考」（`｜提示词：…` / `｜台词：…｜音色：…`）不需要文件，缺台词的音频与按提示词生成的参考视频会报错；`aura_batch_check` 支持 .csv（xlsx 请另存为 csv）；`aura_batch_format` 的说明与模板同步到平台最新口径。
